Тренажер Ланцент СТ-КЭ-01 РЭ

Тренажер для каротидной эндартерэктомии

Профессиональная система для отработки навыков сосудистого шва и эндартерэктомии с активной циркуляцией имитатора крови.

Запросить КП

Раздельное питание

Стабильная работа логики Arduino от сети через Type-C и мощный поток насосов от автономных батарей.

Трехотсечный блок

Изолированные отсеки для электроники, гидравлики и элементов питания для максимальной безопасности.

Биомиметичный сосуд

Сменный модуль имитирует интиму и бляшку, обеспечивая реалистичное сопротивление при эндартерэктомии.

Контроль герметичности

Двухконтурная система создает пульсирующее давление для мгновенной проверки качества сосудистого шва.
